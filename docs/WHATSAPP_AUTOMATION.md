## 🔢 1. Order Reference ID Format

Every booking and order generated by the system creates a unique client-side reference ID:

```javascript
function generateOrderId() {
  const d = new Date();
  const yy = d.getFullYear().toString().slice(-2);
  const mm = String(d.getMonth() + 1).padStart(2, '0');
  const dd = String(d.getDate()).padStart(2, '0');
  const rand = Math.floor(1000 + Math.random() * 9000);
  return `TGS-${yy}${mm}${dd}-${rand}`;
}
```
*Example Output:* **`TGS-260723-4821`** (Date: July 23, 2026, Random Tag: 4821).

## 🛒 2. Menu Mini-Cart Engine

1. **State Storage:** In-memory JavaScript object (`const cart = {}`). Resets on page refresh (by design — no complex backend / stale local storage sync issues).
2. **Item Addition:** Stepper buttons (`.qty-plus` / `.qty-minus`) mutate `cart[itemName] = { qty, price }`.
3. **Floating Cart Bar:** Appears automatically at `bottom: 0` when `totalItems > 0`. Shows live item count and calculated total price in Rupees (₹).
4. **Review Modal:** Modal opens showing itemized list (`2 × Hyd Chicken Dum Biryani — ₹400`), radio options for **Dine-In Table** vs **Takeaway Counter**, and customer Name + 10-digit Phone inputs.
5. **WhatsApp Message Payload:**
   ```
   *New Order — TGS ChefChoice* 🛒

   *Order ID:* TGS-260723-4821
   *Name:* Harish Tangudu
   *Phone:* 9876543210
   *Type:* Dine-In

   • 1 × Hyd Chicken Dum Biryani — ₹200
   • 1 × Chicken 555 — ₹260

   *Total: ₹460*

   _Sent via tgs-chef-choice.vercel.app_
   ```

## 📍 3. QR Code Table Ordering (`?table=X`)

1. **URL Parameter Reader:** When a customer scans a physical table QR code, it opens `https://tgs-chef-choice.vercel.app/menu?table=7`.
2. **Table Banner Injection:** `main.js` detects `table=7`, sets `window.tgsTableNumber = '7'`, and prepends a sticky notification banner at the top of the menu:
   ```html
   <div class="table-order-banner">📍 Ordering for Table 7</div>
   ```
3. **WhatsApp Order Tagging:** When the customer sends their cart order, `main.js` appends `*Table:* Table 7` into the WhatsApp text payload.
4. **Physical QR Code Setup:**
   Generate free QR codes pointing to:
   - `https://tgs-chef-choice.vercel.app/menu?table=1`
   - `https://tgs-chef-choice.vercel.app/menu?table=2`
   - `https://tgs-chef-choice.vercel.app/menu?table=3` ... etc.
   Print, laminate, and attach to restaurant tables!
